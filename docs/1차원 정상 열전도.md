# 1차원 정상 열전도

## 학습목표

- 평면벽·원통·구의 온도분포와 열저항을 유도하고 직렬·병렬 회로로 열전달률을 계산할 수 있다
- 임계 단열 반지름을 구하고 단열재가 오히려 열손실을 늘리는 경우를 판별할 수 있다
- 내부 발열이 있는 벽·봉의 최고 온도를 계산할 수 있다

## 3.1 평면벽

### 온도분포

무발열, $k$ 일정한 평면벽에서 [[열확산 방정식]]은 $\dfrac{d^2T}{dx^2}=0$ 으로 줄어든다. 두 번 적분하고 $T(0)=T_{s,1}$, $T(L)=T_{s,2}$ 를 넣으면

$$T(x) = (T_{s,2}-T_{s,1})\frac{x}{L} + T_{s,1}\qquad q_x = \frac{kA}{L}(T_{s,1}-T_{s,2})$$

온도는 **직선**이고, $q_x$ 와 $q''_x$ 모두 $x$ 에 무관하다.

### 열저항

![[열전달_3.2.png|520]]
*복합벽의 온도 분포와 등가 열회로. 고온 유체 → 벽 A·B·C → 저온 유체*

$$R_{t,cond}=\frac{L}{kA},\quad R_{t,conv}=\frac{1}{hA},\quad R_{t,rad}=\frac{1}{h_rA}$$

양쪽이 유체인 벽이면 대류–전도–대류가 **직렬**이다.

$$q_x = \frac{T_{\infty,1}-T_{\infty,2}}{\dfrac{1}{h_1A} + \dfrac{L}{kA} + \dfrac{1}{h_2A}}$$

### 복합벽

직렬이면 저항을 더한다. 총괄 열전달계수 $U$ 로 묶으면 $q_x = UA\,\Delta T$, $U = 1/(R_{tot}A)$ 다. 열교환기 설계에서 계속 쓰는 형태다.

![[열전달_3.3.png|420]]
*직렬–병렬 복합벽. (a) 열유동에 수직인 면을 등온으로 가정 (b) 평행한 면을 단열로 가정*

직렬과 병렬이 섞인 벽은 가정에 따라 회로가 달라진다. 실제 값은 두 회로의 결과 **사이**에 있다. 이 차이는 열이 옆으로도 흐르는 2차원 효과 때문이다.

### 접촉저항

두 고체를 맞대도 실제로는 거친 표면의 꼭짓점끼리만 닿고 틈새에는 기체가 차 있다. 그래서 계면에서 **온도가 뚝 떨어진다**.

$$R''_{t,c} = \frac{T_A - T_B}{q''_x}\quad[\text{m}^2\text{K/W}]$$

접촉 압력을 높이거나, 표면을 매끈하게 하거나, 틈새에 서멀 그리스·연질 금속박을 넣으면 줄어든다. CPU와 히트싱크 사이에 서멀 페이스트를 바르는 이유다.

### 다공성 물질

![[열전달_3.5.png|520]]
*(a) 실제 다공성 매질 (b) 직렬 극한 (c) 병렬 극한*

고체 + 유체 혼합물은 유효 열전도율 $k_{eff}$ 를 가진 균질 매질로 본다. 두 극한은

- 직렬(층이 열유동에 수직): $k_{eff,min}$
- 병렬(층이 열유동에 평행): $k_{eff,max} = \varepsilon k_f + (1-\varepsilon)k_s$

고체 속에 구형 공극이 드문드문 있으면($\varepsilon \lesssim 0.25$) Maxwell 식을 쓴다.

$$k_{eff} = \left[\frac{k_f + 2k_s - 2\varepsilon(k_s-k_f)}{k_f+2k_s+\varepsilon(k_s-k_f)}\right]k_s$$

## 3.2 전도 해석의 대체 풀이방법

열확산 방정식을 푸는 대신 **Fourier 법칙을 바로 적분**하는 방법이다. 정상·무발열·측면 단열이면 $q_x$ 가 $x$ 에 무관하므로

$$q_x\int_{x_0}^{x}\frac{dx}{A(x)} = -\int_{T_0}^{T}k(T)\,dT$$

단면적이 변하는 원뿔대, $k$ 가 온도에 따라 변하는 재료에 편하다. $k(T)$ 가 선형이면 평균 온도에서의 $\bar k$ 를 쓰면 상수 $k$ 결과와 같은 꼴이 된다. 단, 이 방법은 **1차원 근사가 성립할 때만** 쓸 수 있다. 단면이 급격히 변하면 열이 옆으로도 흐른다.

## 3.3 반지름방향계

### 원통

![[열전달_3.7.png|480]]
*원통 벽의 전도와 등가 열회로*

$$\frac{1}{r}\frac{d}{dr}\!\left(kr\frac{dT}{dr}\right)=0 \;\Rightarrow\; T(r) = \frac{T_{s,1}-T_{s,2}}{\ln(r_1/r_2)}\ln\frac{r}{r_2}+T_{s,2}$$

$$q_r = \frac{2\pi Lk(T_{s,1}-T_{s,2})}{\ln(r_2/r_1)},\qquad R_{t,cond} = \frac{\ln(r_2/r_1)}{2\pi Lk},\qquad R_{t,conv}=\frac{1}{2\pi rLh}$$

온도는 **로그 분포**다. $q_r$ 은 일정하지만 $q''_r$ 은 $1/r$ 로 줄어든다. 면적이 커지니 같은 열이 더 넓게 퍼지기 때문이다.

### 임계 단열 반지름

![[열전달_3.8.png|480]]
*복합 원통벽의 온도 분포와 직렬 열회로*

배관에 단열재를 감으면 두 가지가 동시에 일어난다.

- 단열재가 두꺼워짐 → 전도저항 $\ln(r/r_i)/2\pi Lk$ **증가**
- 바깥 표면적이 커짐 → 대류저항 $1/2\pi rLh$ **감소**

총저항을 $r$ 로 미분해 0으로 두면 저항이 **최소**인 반지름이 나온다.

$$r_{cr} = \frac{k}{h}\ (\text{원통}),\qquad r_{cr}=\frac{2k}{h}\ (\text{구})$$

> [!example] 숫자로 보기
> 반지름 1 mm 전선에 PVC 피복($k = 0.15$ W/m·K), 공기 자연대류 $h = 10$ W/m²·K
>
> $$r_{cr} = 0.15/10 = 0.015\ \text{m} = 15\ \text{mm}$$
>
> 전선 반지름(1 mm)이 $r_{cr}$ 보다 훨씬 작다. 피복을 15 mm 까지 두껍게 할수록 열손실이 **늘어난다**. 전선 피복은 절연이 목적이지만 덤으로 전선 냉각도 돕는다. 반대로 지름 100 mm 증기관은 이미 $r_{cr}$ 을 넘으므로 단열재를 감으면 정상적으로 손실이 준다.

### 구

$$q_r = \frac{4\pi k(T_{s,1}-T_{s,2})}{1/r_1-1/r_2},\qquad R_{t,cond}=\frac{1}{4\pi k}\!\left(\frac{1}{r_1}-\frac{1}{r_2}\right)$$

온도는 $1/r$ 형태다.

## 3.4 1차원 전도 결과의 요약

정상·무발열 1차원 전도 (표 3.3), $\Delta T = T_{s,1}-T_{s,2}$

| | 평면벽 | 원통벽 | 구벽 |
|---|---|---|---|
| 온도분포 | 선형 | $\ln r$ | $1/r$ |
| 열유속 $q''$ | $k\Delta T/L$ | $\dfrac{k\Delta T}{r\ln(r_2/r_1)}$ | $\dfrac{k\Delta T}{r^2(1/r_1-1/r_2)}$ |
| 열전달률 $q$ | $kA\Delta T/L$ | $\dfrac{2\pi Lk\Delta T}{\ln(r_2/r_1)}$ | $\dfrac{4\pi k\Delta T}{1/r_1-1/r_2}$ |
| 저항 $R_{t,cond}$ | $L/kA$ | $\dfrac{\ln(r_2/r_1)}{2\pi Lk}$ | $\dfrac{1/r_1-1/r_2}{4\pi k}$ |

> [!question] 여기서 막힌다
> **원통 식에서 $r_2 \to r_1$ 이면 평면벽이 되나?**
>
> 된다. $r_2 = r_1 + t$, $t \ll r_1$ 이면 $\ln(r_2/r_1) \approx t/r_1$ 이므로 $R = \dfrac{t}{2\pi r_1 L k} = \dfrac{t}{kA}$. 얇은 관을 평면벽으로 근사해도 되는 이유이고, 얼마나 얇아야 하는지는 $t/r_1$ 이 몇 %인지로 판단한다. [[압력용기#1. 얇은 벽 가정]] 과 같은 발상이다.

## 3.5 열에너지 발생이 있는 전도

### 평면벽

![[열전달_3.10.png|480]]
*균일 발열 평면벽. (a) 비대칭 (b) 대칭 (c) 단열 중앙면*

$$\frac{d^2T}{dx^2}+\frac{\dot q}{k}=0\;\Rightarrow\;T(x) = \frac{\dot qL^2}{2k}\left(1-\frac{x^2}{L^2}\right)+\frac{T_{s,2}-T_{s,1}}{2}\frac{x}{L}+\frac{T_{s,1}+T_{s,2}}{2}$$

양쪽 표면 온도가 같으면 **포물선**, 중앙이 최고다.

$$T_0 - T_s = \frac{\dot qL^2}{2k},\qquad T_s = T_\infty + \frac{\dot qL}{h}$$

$T_s$ 는 반쪽 벽에서 발생한 열 $\dot q L$ 이 모두 표면 대류로 나간다는 에너지 평형에서 바로 나온다.

> [!warning] 흔한 오해
> **"발열이 있어도 열저항 회로로 풀면 된다"**
>
> 열저항은 $q$ 가 위치에 무관할 때만 정의된다. 발열이 있으면 $q$ 가 중앙(0)에서 표면(최대)까지 계속 커지므로 **발열 영역 안에서는 저항을 못 쓴다**. 발열 영역 바깥의 피복·외피·대류는 무발열이라 저항 회로를 그대로 쓸 수 있다. 영역을 나눠서 푸는 게 정석이다.

### 원통(봉)

![[열전달_3.11.png|420]]
*균일 발열이 있는 원통 — 전선, 핵연료봉*

$$T(r) = \frac{\dot q r_o^2}{4k}\left(1-\frac{r^2}{r_o^2}\right)+T_s,\qquad T_s = T_\infty + \frac{\dot q r_o}{2h}$$

구는 $T_0-T_s = \dot q r_o^2/6k$, $T_s = T_\infty + \dot q r_o/3h$. 분모의 2·4·6 은 면적/체적 비가 형상마다 다르기 때문이다.

### 도표 결과와 응용

부록 C에 평면·원통·구와 여러 경계조건 조합의 결과가 정리돼 있다. 전선의 Joule 가열은 $\dot q = I^2R'_e/\pi r_o^2$ ($R'_e$: 단위 길이당 전기저항)로 넣는다.
