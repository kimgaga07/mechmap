# 열전달 기초

> [!note] 초안
> Incropera 『열전달』 8판 1장과 절별정리 PDF를 바탕으로 만든 초안이다. 필기로 교체·검수 예정.

## 학습목표

- 전도·대류·복사를 기구(무엇이 열을 나르는가)로 구분할 수 있다
- 세 방식의 전달률 식을 쓰고, 주어진 조건에서 열유속을 계산할 수 있다
- 검사체적과 검사표면에 에너지 보존을 세워 미지 온도나 열전달률을 구할 수 있다
- 열저항으로 바꿔 어느 방식이 지배적인지 판단할 수 있다

## 1.1 열전달이란 무엇이며 어떻게 전달되는가?

열전달은 **온도차 때문에 이동 중인 열에너지**다. 온도차가 있으면 반드시 열전달이 일어나고, 그 방식은 세 가지뿐이다.

| 방식 | 언제 | 무엇이 나르나 |
|---|---|---|
| 전도 | 매체(고체·정지 유체) 안에 온도구배가 있을 때 | 분자·격자진동·자유전자 |
| 대류 | 표면과 움직이는 유체 사이 | 분자 확산 + 유체의 덩어리 운동 |
| 복사 | 유한 온도의 모든 표면 | 전자기파 (매체 불필요) |

열역학은 평형 상태 사이에서 **에너지가 얼마나** 옮겨졌는지를 다룬다. 열전달은 그 일이 **얼마나 빨리** 일어나는지, 즉 전달률(rate, W)을 다룬다. 같은 커피가 식는 문제라도 열역학은 "최종 온도"를, 열전달은 "10분 뒤 온도"를 답한다.

## 1.2 물리적 근원과 전달률 방정식

### 전도

![[열전달_1.2.png|520]]
*고온 쪽 분자가 더 활발하게 움직이며 충돌로 에너지를 넘긴다. 순 에너지 흐름은 온도가 낮아지는 방향*

전도는 분자 활동에 의한 에너지 **확산**이다. 기체·액체에서는 분자 충돌이, 고체에서는 격자 진동(포논)과 자유전자가 에너지를 나른다. 금속이 열을 잘 전하는 이유는 자유전자 때문이다.

1차원에서는 **Fourier 법칙**이 성립한다.

$$q''_x = -k\frac{dT}{dx}\qquad [\text{W/m}^2]$$

정상상태 평면벽에서 온도가 선형이면 $q''_x = k\dfrac{T_1-T_2}{L}$ 이고, 열전달률은 면적을 곱한 $q_x = q''_x A$ [W] 다.

> [!warning] 흔한 오해
> **"음(−) 부호는 그냥 관례다"**
>
> 부호에는 물리가 들어 있다. $dT/dx < 0$ (오른쪽으로 갈수록 차가움)일 때 $q''_x > 0$ 이 되도록, 즉 열이 **온도가 낮아지는 방향**으로 흐른다는 제2법칙을 식에 박아 넣은 것이다. 부호를 빼먹으면 열이 차가운 곳에서 뜨거운 곳으로 흐르는 답이 나온다.

### 대류

![[열전달_1.5.png|520]]
*(a) 강제대류 (b) 자연대류 (c) 비등 (d) 응축*

대류는 분자 확산에 유체의 **거시적 운동**이 더해진 것이다. 표면 바로 위에는 유체 속도가 0인 층이 있어서 거기서는 전도로만 열이 건너가고, 그 위에서 흐름이 열을 쓸어간다. 이 과도 영역이 속도·열 경계층이다.

$$q'' = h\,(T_s - T_\infty)\qquad \text{(Newton의 냉각법칙)}$$

$h$ 는 물성치가 아니라 **유동 조건이 다 녹아 있는 계수**다. 대략적인 크기는 다음과 같다.

| 과정 | $h$ [W/m²·K] |
|---|---:|
| 기체 자연대류 | 2–25 |
| 기체 강제대류 | 25–250 |
| 액체 강제대류 | 100–20,000 |
| 비등·응축 (상변화) | 2,500–100,000 |

### 복사

![[열전달_1.6.png|520]]
*(a) 표면에서의 방사와 조사 (b) 작은 표면과 큰 주위 사이의 복사 교환*

절대온도가 0이 아닌 모든 표면은 전자기파로 에너지를 내보낸다. 흑체의 방사력은 $E_b = \sigma T_s^4$ 이고, 실제 표면은 방사율 $\varepsilon$ 을 곱한다.

$$E = \varepsilon\sigma T_s^4,\qquad \sigma = 5.67\times10^{-8}\ \text{W/m}^2\text{K}^4$$

큰 주위($T_{sur}$)에 둘러싸인 작은 회체 표면($\alpha=\varepsilon$)의 순 복사 열유속은

$$q''_{rad} = \varepsilon\sigma(T_s^4 - T_{sur}^4) = h_r(T_s - T_{sur}),\qquad h_r = \varepsilon\sigma(T_s+T_{sur})(T_s^2+T_{sur}^2)$$

$h_r$ 로 선형화해 두면 대류와 같은 꼴이 되어 둘을 더하기 쉽다.

> [!example] 숫자로 보기
> 표면 $T_s = 400\ \text{K}$, 주위 $T_{sur} = 300\ \text{K}$, $\varepsilon = 0.8$, 공기 자연대류 $h = 10\ \text{W/m}^2\text{K}$
>
> | | |
> |---|---|
> | 대류 | $10 \times 100 = 1{,}000\ \text{W/m}^2$ |
> | 복사 | $0.8 \times 5.67\times10^{-8}(400^4 - 300^4) = 794\ \text{W/m}^2$ |
> | $h_r$ | $794/100 \approx 7.9\ \text{W/m}^2\text{K}$ |
>
> 자연대류에서는 복사가 대류와 **같은 급**이다. "복사는 고온에서만 중요하다"는 생각은 기체 자연대류에서는 틀린다.

### 열저항

전기회로에서 전류 = 전압차 / 저항이듯, 열전달률 = 온도차 / 열저항으로 쓸 수 있다.

$$R_{t,cond} = \frac{L}{kA},\qquad R_{t,conv} = \frac{1}{hA},\qquad R_{t,rad} = \frac{1}{h_r A}$$

같은 표면에서 대류와 복사가 동시에 일어나면 두 저항은 **병렬**이다. 이 사고방식은 [[1차원 정상 열전도]]에서 직렬·병렬 회로로 본격적으로 쓰이고, [[유체 및 열 시스템]]에서는 열용량과 묶여 동적 모델이 된다.

## 1.3 열역학과의 관계

### 제1법칙 — 검사체적

![[열전달_1.8.png|480]]
*(a) 시간 간격 동안의 보존 (b) 순간(전달률) 형태의 보존*

열전달 문제는 거의 언제나 **전달률 형태**의 에너지 보존에서 출발한다.

$$\dot E_{in} - \dot E_{out} + \dot E_g = \frac{dE_{st}}{dt}$$

| 항 | 뜻 | 예 |
|---|---|---|
| $\dot E_{in}, \dot E_{out}$ | 경계를 지나는 에너지 | 전도·대류·복사, 유체 유입·유출 |
| $\dot E_g$ | 내부 발생 (체적 현상) | 전기저항 발열, 화학반응 |
| $\dot E_{st}$ | 저장 에너지 변화율 | 온도 상승 |

정상유동 개방계에서 이상기체나 비압축성 유체라면 $q = \dot m c_p (T_{out} - T_{in})$ 으로 간단해진다.

### 표면 에너지 평형

![[열전달_1.10.png|420]]
*표면을 감싼 검사면. 두께가 0이라 발생도 저장도 없다*

표면은 질량이 없으므로 들어온 만큼 나가야 한다.

$$q''_{cond} - q''_{conv} - q''_{rad} = 0$$

> [!question] 여기서 막힌다
> **검사체적을 어디에 그려야 하나?**
>
> 구하려는 값이 **표면 온도**면 표면에, **내부 온도 변화**면 물체 전체에 그린다. 표면에 그리면 $\dot E_g$, $\dot E_{st}$ 가 자동으로 0이 되어 식이 짧아진다. 반대로 물체 전체에 그리면 표면 사이를 오가는 내부 전도가 보이지 않는다. 풀이 첫 줄에 검사면을 그림에 점선으로 표시하는 습관이 이 혼동을 없앤다.

### 제2법칙과 열기관 효율

Carnot 효율은 $\eta_C = 1 - T_c/T_h$ 지만, 실제 기관은 열원과 작동유체 사이에 **열저항**이 있어서 작동유체가 보는 온도는 $T_{h,i} < T_h$, $T_{c,i} > T_c$ 가 된다. 그래서 실제 효율은 $1 - T_{c,i}/T_{h,i}$ 로 떨어진다. **열전달을 좋게 하면 효율이 오른다**는 것이 열전달과 열역학의 연결점이다.

## 1.4 단위와 차원

| 물리량 | 기호 | 단위 |
|---|---|---|
| 열전달률 | $q$ | W |
| 열유속 | $q''$ | W/m² |
| 단위 길이당 열전달률 | $q'$ | W/m |
| 체적 열발생률 | $\dot q$ | W/m³ |
| 대류계수 | $h$ | W/m²·K |
| 열전도율 | $k$ | W/m·K |

온도**차**는 K와 °C가 같다. 하지만 **복사식과 절대온도가 들어가는 곳에는 반드시 K**를 쓴다. $T^4$ 에 섭씨를 넣으면 답이 전혀 다르게 나온다.

## 1.5 열전달 문제의 해석: 방법론

교재의 모든 예제가 같은 순서를 따른다.

1. **알려진 것** — 문제를 한두 줄로 요약
2. **구할 것**
3. **개략도** — 검사면과 열전달 경로 표시
4. **가정** — 정상/과도, 1차원, 물성 일정, 복사 무시 등
5. **물성치** — 부록 표, 평가 온도 명시
6. **해석** — 보존법칙 + 전달률 식, 숫자는 맨 마지막에
7. **설명** — 결과의 의미, 가정의 영향

결과보다 **가정과 물성 근거**를 남기는 게 핵심이다. 답이 틀렸을 때 어느 가정에서 틀렸는지 거슬러 올라갈 수 있기 때문이다.

## 1.6 열전달의 관련성

![[열전달_1.13.png|420]]
*가스터빈 블레이드 내부 냉각 유로*

| 분야 | 예 |
|---|---|
| 에너지 변환 | 보일러·응축기, 터빈 블레이드 냉각, 연료전지 |
| 전자기기 | 칩 냉각 — 휜, 히트파이프, 액체냉각 |
| 제조 | 주조·용접·열처리, 반도체 공정 |
| 생체·환경 | 체온 조절, 건물 단열 |

설계 목표는 결국 둘 중 하나다. 열전달을 **촉진**하거나(냉각) **억제**하거나(단열).

## 1.7 요약

| 방식 | 전달률 식 | 저항 |
|---|---|---|
| 전도 | $q''_x = -k\,dT/dx$ | $L/kA$ |
| 대류 | $q'' = h(T_s-T_\infty)$ | $1/hA$ |
| 복사 | $q'' = \varepsilon\sigma(T_s^4-T_{sur}^4)$ | $1/h_rA$ |

- 에너지 보존: $\dot E_{in} - \dot E_{out} + \dot E_g = \dot E_{st}$, 표면은 $\dot E_{in} = \dot E_{out}$
- 다음 장 [[열확산 방정식]]에서 Fourier 법칙을 3차원·비정상으로 일반화한다
- 열저항 = 전기저항이라는 비유는 [[전기 회로와 소자]]의 옴의 법칙과 같은 구조다
